How to install

GUIDE
  1. Generate the bookmarklet, then copy its URL.
  2. Create a new bookmark in your browser and edit its URL/address field.
  3. Paste the complete URL beginning with javascript:, then save.
  4. Open a page and click the bookmark to run it. Some sites and browsers restrict bookmarklets.
iPhone / iPad: create a normal bookmark first, then edit its bookmark URL and paste the generated javascript: URL. The exact steps vary by browser; bookmarklets may be restricted in some contexts.
